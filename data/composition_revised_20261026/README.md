# 조성 보고 형태를 보존한 문헌 DB

`database_377.csv`는 기존 377행의 시편 ID·순서·icorr를 유지하면서 조성의 값, 상한, 하한과 출처 정보를 분리한 개발용 DB다. 타깃을 수정하거나 생성하지 않았다. 원래 `data/verified_377.csv`도 변경하지 않았다.

## 원소별 필드

- `{element}_value_wt_pct`: 단일값으로 보고된 함량. 실측·목표·규격 등의 근거는 별도 basis를 확인한다.
- `{element}_lower_wt_pct`, `{element}_upper_wt_pct`: 원문에서 확보한 경계값. 상한만 있으면 하한을 임의로 0으로 만들지 않는다.
- `{element}_reporting_type`: point, interval, upper_bound, lower_bound, unreported.
- `{element}_basis`: 원래 확보된 근거를 보존한다. 미분류 근거는 미해결로 명시한다. 보고된 숫자라는 사실만으로 실측 벌크 분석값이라고 주장하지 않는다.
- `{element}_evidence`: 복구 자료 또는 단위 변환 경로.

C, Si, Mn, P, S, Cr, Ni, Mo, Cu, N에 Nb, Ti, V, Al, W, Co, B, Sn, Sb, Ce, La, Y, O 필드를 추가했다. O는 확인값이 없어 전부 결측이다. 필드가 존재하는 것과 실제로 정보가 확보된 것은 다르다.

기존 검토 원본 45행 중 현재 DB의 record_id와 source_paper_id가 일치하는 37행에서 추가 정보를 복구했다. 보관한 최소 원본은 `recovered_source_rows.csv`이다. 100건의 추가 정보·경계 복구·RE 변환을 `recovery_log.csv`에 기록했다. 이는 신규 문헌 100편 또는 독립 실측 100건을 뜻하지 않는다. 현재값과 복구값의 수치 충돌은 0건이다.

RE 종류가 정확하게 단일 Ce·La·Y로 명시되고 총량이 있는 경우만 ppm/10000으로 해당 원소 wt.%를 계산했다. 혼합 RE의 총량을 임의로 분배하지 않았다. 개별 Ce·La가 확인된 혼합 시편 1행은 각 함량 합계가 기존 총 RE와 일치한다.

실제 확보한 조성 경계는 상한 39셀이고 하한·양측 구간의 원문값은 없다. 하한·구간 스키마는 향후 자료를 위한 것이며 새 정보를 만들어 채우지 않았다. 기존 처리에서 빠졌던 상한을 복구했다.

기존의 일부 보완 표시가 source-only 숫자와 맞지 않을 수 있어 `legacy_` 접두사로 옮겼다. 이 열은 모델 피처가 아니다. source-only가 모든 행의 출처·실측성을 완전히 재감사했다는 의미는 아니다.

## 모델 입력에서의 처리

단일값, 하한, 상한과 보고 형태를 함께 표현하는 방식을 비교한다. 단일값의 모델용 양 끝점은 그 값으로 설정할 수 있지만 원본 DB의 보고 경계 열은 변경하지 않는다. 경계값의 절반이나 구간 중간값을 실측 조성으로 대입하지 않는다. 미보고 조성을 무첨가 0으로 만들지 않는다. 구조화 방식에서는 타 논문의 donor 조성 대체를 사용하지 않고 학습분할 중앙값 대체와 보고 형태를 사용한다.

이 입력 방식은 구간 불확실성을 수학적으로 전파하는 모델이 아니다. 일반 SVR에 정보 형태를 명시하는 feature engineering이다. 미보고·보고 패턴이 출처를 대신 학습하는 문제는 여전히 있을 수 있다.

성능 비교는 `results/composition_revised_20261026`에 저장한다. 기존 predict CLI는 이 DB로 자동 재학습되지 않으며 저장 운영 모델도 교체하지 않는다.
