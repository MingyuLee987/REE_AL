# 추가 모델 비교와 VAE 실험

검토한 정제 데이터 전체 304행을 사용했습니다. 행·목표값을 삭제하거나 고치지 않았으며, 기존 seed 42/43/44의 논문 홀드아웃을 유지했습니다. 이번 작업은 모델 선택과 입력 표현을 개선한 실험이며 새로운 논문 검증을 추가한 작업은 아닙니다.

## 변경 사항

- 기본 입력과 **로그 시간·로그 RE 함량, 전해질 계열, 명시적 NaCl wt.%/mol/L**를 보완한 입력을 비교했습니다. 농도 기준이 없는 `3.5%`는 wt.%로 가정하지 않았습니다. 원문 전해질 문자열은 유지하므로 추가 계열만으로 서로 다른 전해질을 동일시하지 않습니다.
- 평균 기준선, Ridge, Random Forest, Extra Trees, HistGradientBoosting, RBF SVR을 작은 고정 탐색 공간에서 비교했습니다.
- 잠재 2/4차원 VAE+Ridge와 감독 보조 손실을 더한 4차원 VAE+Ridge를 추가했습니다.
- 각 외부 학습 집합 안에서 3-fold GroupKFold의 OOF log10 RMSE로 모델과 설정을 선택했습니다. 대치·스케일링·범주 인코딩·VAE를 내부 학습 fold에서만 학습했습니다.
- 테스트 R²로 최종 설정을 선택하지 않았습니다. 각 모델 계열의 결과도 내부 CV로 선택한 설정만 평가했습니다.
- 추천용으로는 논문 bootstrap 위원회를 학습해 예측 불확실성을 구하도록 했습니다. VAE의 잠재분포 표준편차를 LCB 불확실성으로 재사용하지 않습니다.

## 실행 결과

아래는 세 외부 홀드아웃 점수의 단순 평균이며 모두 log10 목표 기준입니다. 행별 예측을 합쳐 계산한 R²는 아닙니다.

| 평가 방식 | 평균 테스트 R² | 평균 RMSE | 평균 MAE |
| --- | --- | --- | --- |
| 이전 정제+공정 Random Forest 고정 | 0.0374 | 0.9706 | 0.8339 |
| 내부 논문 CV로 모델·입력 선택 | 0.0346 | 0.9790 | 0.8148 |
| Random Forest 계열 내부 CV 선택 | 0.0150 | 0.9752 | 0.8372 |
| Extra Trees 계열 내부 CV 선택 | -0.0744 | 1.0240 | 0.8661 |
| 부스팅 계열 내부 CV 선택 | -0.0374 | 1.0140 | 0.8376 |
| SVR 계열 내부 CV 선택 | -0.0196 | 1.0035 | 0.8080 |
| Ridge 계열 내부 CV 선택 | -2.1205 | 1.6271 | 1.2031 |
| VAE 계열 내부 CV 선택 | -0.4391 | 1.1945 | 0.9790 |
| 학습 평균 기준선 | -0.2642 | 1.1114 | 0.8642 |

**평균 R²나 RMSE의 추가 개선은 확인되지 않았습니다.** 내부 CV 선택은 평균 MAE가 약 2.3% 낮았지만 RMSE와 R²는 약간 악화됐습니다. 세 번의 반복만으로 통계적 우위를 주장하지 않습니다. 테스트를 본 뒤 가장 유리한 계열이나 seed를 골라 개선된 결과로 보고하지 않았습니다.

| seed | 이전 고정 RF R² | 내부 CV 선택 모델 | 선택 모델 R² | VAE 계열 선택 R² |
| --- | --- | --- | --- | --- |
| 42 | -0.1286 | Extra Trees / 보완 입력 | 0.0097 | -0.2535 |
| 43 | 0.1541 | 부스팅 / 기본 입력 | 0.2539 | -0.0157 |
| 44 | 0.0868 | Extra Trees / 보완 입력 | -0.1599 | -1.0480 |

VAE 계열에서는 세 경우 모두 내부 CV가 비감독 2차원 VAE+Ridge를 선택했습니다. 감독 보조 손실 모델도 내부 CV에서 더 좋은 결과를 얻지 못했습니다. 이는 **이번 소형 구조·고정 학습 설정**의 결과입니다. 모든 VAE 구조나 충분한 비감독 데이터가 있는 경우의 가능성까지 부정하는 결과가 아닙니다.

기존 테스트 분할은 이전 보고서에서도 관찰했습니다. 이번 내부 모델 선택에 직접 사용하지 않았더라도, 반복적인 개발에 재사용된 평가셋이므로 최종적인 독립 검증으로 보기는 어렵습니다. 새로운 실험실 데이터 또는 개발 과정에서 관찰하지 않은 별도 논문 집합을 확보해야 합니다.

## 최종 학습 모델과 추천

`--fit-final`로 전체 304행 내부 CV를 별도로 수행했을 때는 기존 기본 입력 Random Forest가 선택됐습니다. 이 모델의 전처리와 본체를 `outputs/model_selection/final_model.joblib`에 저장했고, 설정은 같은 경로의 `final_config.json`에 있습니다. 전체 데이터 학습은 배포·후보 평가용이며 자체적으로 독립 테스트 결과를 제공하지 않습니다.

`recommend_advanced.py`는 선택된 설정을 사용해 논문별 bootstrap 위원회를 새로 학습합니다. 최종 저장 모델의 단일 예측을 위원회 표준편차인 것처럼 사용하지 않습니다. VAE 구성 파일로 바꾸면 같은 방식으로 여러 VAE+회귀 모델을 학습합니다. 자세한 가이드와 명령은 [VAE_GUIDE.md](../VAE_GUIDE.md)를 참조하십시오.

## 재현

```powershell
python -m pip install -r requirements.txt
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python improve_models.py --include-vae --fit-final
python -m unittest discover -s tests -v
```

주요 출력은 `outputs/model_selection/`의 search_space.json, training_cv.csv, metrics.csv, predictions.csv, splits.csv, summary.csv, run.json과 저장 모델입니다. `final_training_cv.csv`는 외부 홀드아웃 결과와 별도의 전체 데이터 CV입니다. 정제 데이터 해시와 라이브러리 버전은 run.json에 남깁니다. 새로 실행할 때 다른 output 경로를 사용하면 기존 결과를 보존할 수 있습니다.

다음 우선순위는 잠재 차원을 계속 바꾸며 같은 테스트 R²를 보는 것이 아니라, 미검증·그림 유래 레이블의 품질 개선과 동일 강종·환경에서의 실측 확보입니다. 현 상태에서 VAE가 성능을 개선한다고 판단할 근거는 없으므로, 기존 RF를 기준선으로 유지하고 VAE는 비교 실험으로 사용하는 편이 타당합니다.
