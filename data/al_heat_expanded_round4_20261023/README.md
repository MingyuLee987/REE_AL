# 300행 목표 수집 결과

## 이번 버전의 실제 검토 방식과 제한

기존 237행의 타깃을 보존하고 11개 출처의 99행을 추가했습니다. 전체 336행/57개 출처이며, icorr와 온도·시간이 확인된 별도 CSV는 317행입니다. 300행 목표는 확인본 기준으로 충족했습니다. 확인본도 조성·시험조건 결측이 남아 있으므로 모든 피처가 실측된 완전 학습자료를 뜻하지 않습니다.

추가 RE 양성 자료는 Ce 95 ppm S31254강 12행과 La 4900 ppm 초오스테나이트강 2행입니다. Ce 0.0095 wt.% 및 La 0.49 wt.% 벌크 분석값을 각각 10000배하여 ppm으로 변환했습니다. 명목 La 0.5 wt.%와 실측 La 0.49 wt.%를 구분했습니다. Ce 무첨가 비교군 4행과 La 무첨가 비교군 1행도 포함했습니다. 같은 논문에서 여러 시험조건을 측정한 행들이며, 서로 다른 독립 논문 14편을 뜻하지 않습니다.

수집 중 OpenAI API가 HTTP 429, credit_balance_exhausted를 반환했습니다. 이후 API 호출을 중단하고 이미 확보한 원문을 직접 대조했습니다. API 보조 검토와 직접 대조를 target_review_status 및 new_source_provenance.csv의 method에서 구분합니다. 직접 대조 기록은 scripts/verify_heat_round4_primary.py와 outputs/heat_expansion_round4_manual_20261023/에 있습니다. 직접 검토를 별도 API 재검토라고 표기하지 않았습니다.

Ce 문헌은 출판사 HTML Table IV의 rowspan을 기계적으로 전개하여 S0/S2 시편 대응을 복구했습니다. 0분 미처리/반복 기준값은 제외했습니다. 나노유체 담금질 탄소강 40행은 공개 PDF 7–8쪽 Tables 5–6의 Icorr 열과 Table 2의 열처리를 직접 대조했습니다. 표에 인쇄된 전류밀도를 보존하며, 인접 부식률과 불일치하는 값을 부식률로 역산하여 수정하지 않았습니다. 담금질 냉각매체 차이는 메타데이터로 남겼으며 공정 입력은 요청대로 온도와 시간 두 개뿐입니다. 이 두 피처만으로 냉각매체·다단계 이력의 효과를 분리할 수 없습니다.

온도·시간과 icorr는 통계적으로 채우지 않았습니다. 조성만 제공 PDF의 출처/proxy/범위 가정/같은 계열의 논문 간 donor 정책을 따릅니다. 전체 검토본의 전역 조성 보완값은 검토용이며, 평가 시 논문 단위 분리와 fold 안에서의 보완이 필요합니다. RE 미보고는 0으로 채우지 않았습니다. 기존 운영 CSV와 모델 파일은 그대로 보존했고 재학습하지 않았습니다.

전체 검토본의 온도·시간 결측은 각 19/336행(5.65%)이고, 317행 확인본에서는 각각 0%입니다. 조성·환경별 결측은 missingness.csv(336행)와 missingness_checked_labels.csv(317행)를 구분해서 확인하세요.

# 열처리 온도·시간 피처를 사용하는 문헌 시험데이터 확장

기존 45행에 원문 근거와 API 보조 재검토 또는 원문 직접 대조를 통과한 291행을 추가했습니다. 전체 336행, 57개 출처입니다. 이는 서로 다른 논문 수나 독립 반복실험 수와 같은 의미가 아닙니다. 각 행의 실제 검토 방식은 target_review_status와 provenance의 method를 확인하세요.

## 사용할 파일

- al_labeled_heat_treatment_expanded.csv: 기존 행을 보존한 전체 검토본. 미검증 기존 타깃도 상태 표시와 함께 보존합니다.
- al_heat_checked_labels.csv: icorr 타깃과 열처리 온도·시간을 확인한 317행. 조성·시험조건 결측은 남아 있습니다.
- al_heat_core_review.csv: 조성 10개와 전해질·시험온도 정보(명시된 실온 포함)·주사속도까지 확보/보완한 97행. 조성 추정값이 포함되므로 모두 실측 완전자료라는 뜻은 아닙니다. pH·침지시간·OCP·RE 등의 결측도 별도로 확인해야 합니다. 모든 선택 피처가 완비됐다는 의미가 아닙니다.
- source_only_before_composition_imputation.csv: 조성 통계 보완 전 자료와 출처 정보. 기존 45행의 원문/proxy 이력은 이전 data/al_curated_20261023/source_and_proxy_provenance.csv도 함께 참조합니다.
- paper_group_fold_*.csv: 해당 fold의 검증 논문을 조성 donor와 IQR 산정에서 제외한 데이터. target_verified와 열처리 조건을 확인한 뒤 사용해야 하며, 이 파일 자체가 성능 검증 결과는 아닙니다.

## 실제 피처

공정 피처는 heat_treatment_temperature_C와 heat_treatment_time_min 두 개뿐입니다. 결정립 크기·상·냉각방법·압연·용접 피처는 모델 입력에서 제외했습니다. 모든 입력 컬럼은 feature_schema.json의 predictor_columns에 명시했습니다. source_paper_id, heat_treatment_stage, heat_history_note, 검토/추정 상태 등은 출처·감사 메타데이터이며 피처가 아닙니다.

온도·시간 두 값만으로 다단계 이력을 완전히 표현할 수 없습니다. 신규 추출은 마지막 명시적 등온 유지단계를 선택하고 앞선 이력을 메타데이터에 기록했습니다. 기존 자료는 이전에 확인한 단계를 보존합니다. 예를 들어 ma15248780은 용체화, ma18081823은 시효, ma19122685는 압연 전 빌릿 재가열입니다. 따라서 서로 다른 처리 단계를 단순히 동일한 열처리로 해석해서는 안 됩니다. 같은 강종·같은 열처리 단계·같은 시험환경에 한정한 AL을 우선 권장합니다.

## 수집·검증과 결측 보완

추가 문헌 102편을 처리했습니다. OpenAI API로 원문 표·실험조건을 추출하고, 별도 모델 호출로 단위·시편·타깃·온도/시간 연결을 재검토했습니다. 인용문이 실제 확보한 본문에 그대로 존재하는지도 코드로 확인했습니다. 이는 API 보조 검증이며 사람이 모든 원문을 독립 검토한 자료라고 주장하지 않습니다. 모든 신규 값의 인용문·원문 위치·원래 단위는 new_source_provenance.csv에 있습니다. 억제제·코팅·비철/금속간화합물·미처리 시편의 미보고 열처리값·부식률/부동태전류 등은 추가하지 않았습니다.

열처리 온도·시간과 icorr는 추정하지 않았습니다. 조성은 제공 PDF의 정책에 따라 원문/동일 논문 모재를 우선하고, 상한의 1/2 또는 범위 중간값을 명시적 가정으로 구분합니다. 사전 입력이라는 목적에 맞춰 ma17122807의 분말 조성과 s41598-024-75382-5의 와이어 조성을 Table 1에서 직접 확인하여 feedstock proxy로 보존했습니다. 이는 PDF의 모재 proxy 원칙을 원료에 확장한 선택이며 제조 후 벌크 실측값이 아닙니다. composition_input_basis와 provenance의 manual_verified_Table1_feedstock_proxy로 구분합니다. 그 외 API 검토에서 거절된 조성을 임의 복구하지 않았습니다. 나머지는 같은 강종 계열, 관측 원소 2개 이상 겹침, IQR 거리 기준 3–5개 다른 논문의 중앙값을 사용합니다. donor가 3개 미만이면 결측으로 둡니다. 타깃은 조성 보완에 전달하지 않습니다. 통계 추정 조성을 재차 donor로 넣지 않습니다.

전체 검토본의 조성 보완값은 독립 검증에 바로 사용하면 안 됩니다. 논문 단위로 분리한 뒤 fold별 보완값을 사용해야 합니다. RE 첨가량과 실제 잔류량/분석 조성은 제조 전에 동일하게 알려지는 정보가 아니므로, 실제 AL 후보에는 명목 배합과 잔류 분석값의 구분이 추가로 필요합니다. RE 미보고를 0으로 채우지 않았습니다.

## 접근 제한과 원문 충돌

Elsevier 검색 API는 단순 검색식 재시도로 20건의 메타데이터를 받았으나, 추가 15편의 FULL 원문 요청은 HTTP 403이었습니다. Springer metadata/OA는 HTTP 403이었습니다. Wiley TDM은 10.1002/eng2.12105 PDF를 받았습니다. 이 논문은 방법의 H2SO4 0.05 M과 결과/표의 2 M 표기가 충돌하여 새 학습행으로 추가하지 않았습니다. 접근하지 못한 원문 수치를 추측해 채우지 않았습니다.

온도·시간 결측은 전체 검토본에서 각각 19/336행(5.65%)입니다. 나머지 피처 결측률은 missingness.csv를 확인하세요. 기존 운영 모델과 data/training.csv는 수정하거나 재학습하지 않았습니다.

추가 291행은 일반강·스테인리스강의 열처리/부식 시험 확장입니다. 이 추가분에서 명시적인 RE_ppm > 0인 행은 16행입니다. 이를 RE 첨가 내부식강 시험을 291행 새로 확보했다는 의미로 해석하면 안 됩니다. 숫자 시험온도 또는 명시된 실온/주변온도 정보가 모두 없는 행은 전체 65행입니다.

## 300행 목표 추가 수집

직전 237행 자료를 보존한 별도 버전입니다. 이번에 11개 출처의 99행을 추가하여 전체 336행을 만들었습니다. 열처리 쌍과 타깃을 확인한 행은 317행입니다. 전체 검토본과 확인본의 행 수를 혼용하지 않습니다. 이번 추가분만 보려면 new_rows_this_round.csv를 사용하세요.

희토류 첨가 강재를 우선 확인하되 일반 철강의 열처리·전기화학 시험도 포함했습니다. 그래프만 제공된 수치를 임의 추정하거나 미보고 조건을 복제하여 행 수를 늘리지 않았습니다. 문헌 원문 수집·소규모 API 추출 이력은 outputs/heat_expansion_round4_20261023/에 있습니다.

앞서 생성한 열처리 방법 PDF의 179행 집계는 당시의 이력입니다. 현재 CSV의 집계는 이 폴더의 summary.json과 missingness.csv를 기준으로 합니다. 모델은 이번 자료로 재학습하지 않았습니다.
