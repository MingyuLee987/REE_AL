# 원문 대조와 정제 데이터 평가

검토일: 2026-10-22. 원본 304개 기록, 48개 출처 중 **20편·174개 기록의 관련 방법·표·그림 출처를 검토**했습니다. 모든 숫자를 실측 표와 대조했다는 뜻은 아닙니다. 원문 접근 실패, 초록만 확보, 그림에서 읽은 값, 단위 불일치를 구분했습니다. 나머지 28편·130개 기록은 원문 검증 미완료입니다.

원본 XLSX와 부식전류 목표값은 바꾸지 않았습니다. [정제 CSV](../data/curated_corrosion.csv)는 전체 304행을 유지한 보수적 정제본입니다. 원문 검증이 끝난 304행이라는 의미가 아닙니다. [논문별 검토 범위](paper_review.csv), [셀별 변경 근거](changes.csv), [원본 해시와 변경 집계](curation_manifest.json)를 함께 사용하십시오.

[접근 상태 목록](access_inventory.csv)에는 48개 출처의 요청 URL, 응답 상태, PMC 대체 원문 여부와 실제 검토 범위를 구분했습니다. Springer/Nature의 접근 가능한 본문과 표, Europe PMC의 공개 저자 논문 XML을 사용했습니다. 출판사에서 HTTP 200으로 접근 확인 페이지만 반환한 경우는 원문 확보로 계산하지 않았습니다.

**“본문에서 찾지 못함”은 해당 수치가 틀렸다는 확정이 아닙니다.** 기존 원자료의 산출 근거나 별도 보충자료가 있을 가능성을 남겨 두고, 현재 확보한 원문으로 뒷받침할 수 없는 정확값을 보수적 분석에서 제거했습니다. 따라서 이 정제본은 확인된 전사 오류 수정과 미확인 가정 제거를 함께 포함하는 민감도 분석용 데이터입니다.

총 821개 셀 변경 중 기존 모델 입력 열의 변경은 339개이며, 나머지 482개는 새 조건·상한·공정 열의 보완입니다. 기존 입력 변경 339개 중 324개는 근거를 확인하지 못한 정확값 또는 상한값을 결측으로 옮긴 경우입니다. **821개의 오류를 발견했다는 뜻은 아닙니다.**

## 목표값의 검증 상태

정제 CSV의 `target_review_status`를 확인하십시오. ID·출처·이 상태 열은 모델 입력에서 제외됩니다.

| 상태 | 행 수 | 의미 |
| --- | --- | --- |
| table_numbers_and_units_checked | 51 | 원문 표의 숫자와 단위 환산 대조 |
| body_number_and_unit_checked | 7 | 본문 수치와 단위 대조 |
| figure_values_not_redigitized | 98 | 그림 출처 확인. 기존 값을 다시 디지타이징하지 않았으므로 정확값 검증 완료가 아님 |
| numbers_match_unit_ambiguous | 15 | 숫자는 표와 일치하나 인쇄 단위가 Amp/cm로 모호 |
| numbers_match_printed_unit_typo | 2 | 숫자는 일치하나 표의 인쇄 단위에 제곱·역수 표기 문제 |
| source_internal_numeric_conflict | 1 | 논문 내부에서 같은 시료의 숫자가 불일치 |
| not_verified | 130 | 이번 원문 대조 미완료 |

HRB500E의 C2 값은 본문에서는 3.35 mA/cm², 결론에서는 6.350 mA/cm²로 다릅니다. 엑셀은 본문 값을 따르고 있습니다. 원문 내부 문제이므로 임의의 값으로 바꾸지 않았습니다. [해당 논문](https://www.nature.com/articles/s41598-024-67799-9)

AISI 202 논문의 Tables 5–7은 전류 단위를 Amp/cm로 인쇄했습니다. 노출 면적은 1 cm²지만, 이를 근거로 인쇄 오류를 확정하지 않았습니다. 저장된 15개 숫자는 일치하며 단위는 미해결로 남겼습니다. [Table 5](https://link.springer.com/article/10.1007/s11665-015-1651-6/tables/5)

Fe–Nb–B–Dy/Tb 비정질 합금과 Fe계 금속유리도 섞여 있습니다. 일반 강의 RE 미량첨가 최적화와 연구 범위가 다를 수 있지만, 이번 전후 성능 비교에서는 행을 제거하지 않았습니다. 연구 범위를 정의한 다음 포함 여부를 결정해야 합니다. [비정질 합금 논문](https://link.springer.com/article/10.1007/s11003-015-9767-2), [금속유리 논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC7919831/)

## 동일 테스트셋 평가

seed 42/43/44, 논문 그룹 약 20% 홀드아웃, log10(icorr_A_cm2), 동일한 150-tree Random Forest 설정을 사용했습니다. 행·목표값·논문 그룹은 전후 동일합니다. 데이터나 모델의 선택을 위해 테스트 R²를 탐색하지 않았습니다. 이 결과를 본 뒤 추가 모델 선택을 한다면 학습 데이터 내부의 별도 논문별 검증을 사용해야 합니다.

`random80`은 기존 모의 AL의 random 전략과 같은 초기 40개와 8×5개의 추가 ID입니다. `full_train`은 각 테스트 논문을 제외한 277/240/248개 전체 학습 행입니다. 두 예산의 결과를 서로 같은 실험처럼 비교하지 않습니다.

| 학습 예산 | 데이터/입력 | 평균 log10 MAE | 평균 log10 RMSE | 평균 테스트 log10 R² |
| --- | --- | --- | --- | --- |
| 전체 학습 | 원본 기본 입력 | 0.9190 | 1.0936 | -0.2345 |
| 전체 학습 | 정제 기본 입력 | 0.8563 | 0.9921 | -0.0035 |
| 전체 학습 | 정제 + 공정·조건 입력 | 0.8339 | 0.9706 | 0.0374 |
| 전체 학습 | 학습 평균 예측 기준선 | 0.8642 | 1.1114 | -0.2642 |
| 80개 | 원본 기본 입력 | 0.8596 | 1.0252 | -0.0740 |
| 80개 | 정제 기본 입력 | 0.8789 | 1.0321 | -0.0945 |
| 80개 | 정제 + 공정·조건 입력 | 0.8782 | 1.0369 | -0.1033 |

전체 학습의 정제+공정 모델 R²는 seed별 -0.1286, 0.1541, 0.0868입니다. 평균의 표준편차가 아니라 **세 R² 값의 표본 표준편차**는 0.1477입니다. seed 42는 원본보다 악화됐습니다. MAE 0.8339는 기하평균 절대 오차 배율 약 6.8배에 해당하므로, 실험 후보를 정밀하게 최적화할 수준이라고 해석하기 어렵습니다. 평균 R²는 각 홀드아웃의 R²를 단순 평균한 값이며 모든 예측을 합쳐 계산한 R²가 아닙니다.

정제는 전체 학습 조건에서 평균 성능을 개선했지만, 80개 예산에서는 개선되지 않았습니다. 행을 잘라 내거나 테스트 분할을 골라 점수를 올리지 않았습니다. raw 데이터를 모두 넣으면 점수가 자동으로 좋아지는 것도 아닙니다. 아직 부족한 조건, 그림 추출 오차, 논문 간 체계적 차이를 함께 해결해야 합니다.

실행 결과는 `outputs/curation_benchmark/`의 metrics.csv, predictions.csv, per_paper_errors.csv, splits.csv, summary.csv 및 run.json에 있습니다. splits.csv로 원본·정제 전후 테스트 ID가 같음을 확인할 수 있습니다.

## 재실행

```powershell
python curate_data.py
python evaluate_curation.py
python active_learning.py simulate --data data/curated_corrosion.csv --with-process --output outputs/curated_al
```

`--with-process`는 열처리 온도·시간, OCP 안정화 시간, pH 하한, P/S 상한과 공정·시험 영역·정성적 온도 범주를 사용합니다. 후보 추천에도 사용할 수 있지만 후보 CSV에 해당 열을 모두 만들고 후보를 선택하는 시점에 알 수 있는 값만 채워야 합니다. 모르는 값은 빈칸으로 둡니다. 원문 검증 상태나 출처 ID를 설명변수로 넣지 않습니다.

원문 재수집은 다음과 같이 실행합니다. 접근 결과는 시점·기관 구독·사이트 상태에 따라 달라집니다. 재수집이 검증 판정이나 정제 규칙을 자동 변경하지는 않습니다. HTML 200 응답이 초록이나 접근 확인 페이지인 경우도 있어 수집과 검증을 분리했습니다. 원문 캐시는 outputs 아래에만 보존합니다.

```powershell
python fetch_papers.py
python fetch_papers.py --tables
python fetch_papers.py --pmc
python fetch_papers.py --inventory
```

## 다음 데이터 보완 우선순위

1. **미검증 28편·130행의 원문/보충자료 확보:** paper_review.csv에 해당 목록을 남겼습니다. 접근 실패를 검증 완료로 취급하지 않습니다.
2. **그림 유래 98개 값 재추출:** 축의 log/linear 척도·단위·시료 순서를 확인하고, 피팅된 icorr가 있는지 먼저 찾습니다. 분극곡선에서 읽은 임의 전류를 Tafel 피팅 icorr와 동일하게 취급하지 않습니다. 숫자 디지타이징 불확실성을 저장해야 합니다.
3. **논문 내 모순·단위 미해결 18행 확인:** C2 1행, AISI 202 15행, CGHAZ 2행입니다. 원자료/정오표를 확보하기 전까지 별도 표식을 유지합니다.
4. **원하는 실험 환경으로 범위 정의:** 강종·전해질·열처리·모재/용접/HAZ를 먼저 정합니다. 점수를 확인한 뒤 유리한 행만 제외하는 방식으로 범위를 고르지 않습니다.
5. **작은 실측 초기 설계 확보:** 현재 문헌 데이터로 높은 R²나 LCB의 신뢰수준을 보장할 수 없습니다. 동일 실험실 조건의 반복 측정과 대조군을 확보하고, 그룹 검증을 통과한 모델로 AL을 시작하는 것이 다음 연구 단계입니다.
