# 현재 모델과 데이터 원칙

## 유지한 모델

models/svr.joblib 하나에 조성 보완 → 환경 피처 → 결측 대체·인코딩·스케일링 → 중앙 SVR 및 부트스트랩 위원회가 들어 있습니다. SVR은 C=10, epsilon=0.15, RBF kernel, gamma=scale입니다. 15개 부트스트랩 모델은 후보 선택용 불확실성을 계산하며 보정된 신뢰구간이 아닙니다.

입력은 기존 환경 변수 74개입니다. 상분율·측정 i_corr·논문 ID를 모델 설명 피처로 사용하지 않습니다. 논문 ID는 조성 donor 출처 제어용으로만 사용합니다. 미상 농도를 임의로 만들거나 밀도 없이 wt%를 M으로 변환하지 않습니다.

## 학습 자료

data/training.csv는 279행 / 43개 논문의 **통계적 조성 보완 전** 준비 자료입니다. 원래 알려진 조성 donor와 누락 표시를 포함합니다. 학습 시 통계적 조성 보완과 다른 전처리는 그 학습 분할 안에서만 계산합니다. 원래 조성표·추정 범위·제외 이력은 data/provenance에 보존했습니다.

data/literature는 추가 확보한 자료입니다. 확인한 측정값 503개와 자동 후보 4,648개를 구분했으며 기존 279행에 자동 합치지 않았습니다. 환경 전용·조성 미상·코팅·억제제·비철 자료와 중복을 검토해야 합니다.

## 평가

기본값은 행 기준 무작위 KFold 5개, shuffle=True, random_state=42입니다. 같은 논문의 다른 행이 양쪽에 포함될 수 있습니다. 현재 고정 SVR의 평균 테스트 R²는 0.8178, log10 기준입니다. 과거 18개 모델 선택 절차의 0.7973과는 평가 대상이 다르며 과거 비교 결과는 백업에 보존했습니다.

AL은 테스트 입력·정답을 후보 선택에서 제외하고 학습 풀 25%에서 시작해 10개씩 조회했습니다. 무작위·부트스트랩 불확실성·불확실성+다양성을 두 초기 seed에서 비교했습니다. 50% 조회 평균 테스트 R²는 무작위 0.6094, 하이브리드 0.7522였으며 75%에서는 0.7737과 0.8137입니다. 회고적 모의실험으로 새 실험실에 대한 보장은 아닙니다.

## 정리 범위

RF·ExtraTrees·Ridge·Boosting·SHAP 축소 모델과 중간 결과, 수집 도구·원문 캐시·검토 기록의 이전 폴더는 작업 폴더 밖 백업으로 옮겼습니다. 원본 데이터를 삭제하지 않았습니다. 백업 위치와 이동 대상은 cleanup_manifest.json에 있습니다.

모델 가중치를 그대로 두고 Python 클래스 경로만 현재 패키지로 변경했습니다. 이 과정에서 모델 파일 해시는 달라지지만 279행의 예측값과 불확실성은 기존 모델과 일치합니다. 이전 해시로 동결한 실험 기록이 있다면 백업에 있는 이전 모델을 사용해야 합니다.
