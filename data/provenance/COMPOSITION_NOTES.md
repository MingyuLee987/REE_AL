# 조성 보완 데이터

`composition_estimated_revised.xlsx`의 `ENRICHED_DATA`가 조성 보완·행 제외를 적용한 데이터입니다. 같은 내용의 `composition_estimated.csv`도 제공합니다. 기존 `curated_corrosion.csv/xlsx`와 저장된 RF 모델은 보존했습니다.

- 원본 304행 중 279행·43개 논문을 유지하고, 조성 근거가 부족한 25행을 제외했습니다. 제외 기준은 원문·강종·기존 조성에서 식별 가능한 핵심 조성 항목이 2개 미만인 경우입니다. 제외는 부식 전류나 모델 점수와 무관합니다.
- 핵심 원소 C·Si·Mn·P·S·Cr·Ni·Mo·Cu·N에서 959개 빈 값을 보완했습니다. 161행은 이 10개 항목이 채워졌고, 118행은 부분 조성입니다. 총 230개 빈 값은 유지했습니다.
- 기존 핵심 조성의 기입값과 모든 부식 전류 타깃은 그대로 유지했습니다. 기존 기입값 전체가 새로 원문 검증됐다는 의미는 아닙니다.

## 보완 방법과 해석

1. **원문 복구:** iScience 논문의 보충 Table S1에서 Cr·Ni·Mo·N을 복구했습니다. HAZ 국부 조성 대신 모재 조성을 사용한 근사입니다. P·S의 `<0.01 wt.%`는 상한을 따로 기록하고 대표 추정값 0.005를 넣었습니다. 이는 측정값이 아닙니다. Ce 첨가 시료 8행의 RE_ppm은 Table S1의 실제 모재 Ce 함량으로 교정했으며 이전 값은 로그에 보존했습니다.
2. **동일 논문 모재 추정:** Q235M·09CuPCrNiM의 누락 조성은 해당 논문의 대응 모재를 대리값으로 사용했습니다. RE 처리 후 실제 조성이 동일하다는 검증은 아닙니다.
3. **강종 대표값:** 304·316·316L은 제조사의 대표 조성, 75Cr1은 공개 조성 범위 중간값을 사용했습니다. 해당 논문 시료의 실측 조성이나 규격 보증값으로 해석하지 않습니다.
4. **명목 배합과 제외:** Fe-B9의 명시된 원자 배합을 wt.%로 환산해 보존했습니다. 배합식에 없는 원소의 명목 무첨가 가정은 셀 로그에 표시했습니다. Fe-Nb-B-Dy/Tb 14행은 주요 B·Nb 조성을 현재 RF 입력으로 표현하지 못하므로 제외했습니다. 앞서 C~N에 넣은 명목상 0은 철회하고 미보고 값은 빈칸으로 복원했습니다. 해당 합금의 명목 B·Nb·Fe·Dy·Tb 조성은 제외 기록에 보존했습니다.

5. **유사 합금 통계 추정:** 같은 강종 계열의 다른 논문에서 이미 조성이 기입된 관측을 사용했습니다. 알려진 원소가 최소 2개 겹치는 후보를 조성 거리로 정렬해 최대 5개 논문, 최소 3개 논문의 원소별 중앙값을 사용했습니다. 같은 논문의 반복 실험이 여러 표를 행사하지 않게 논문당 하나만 사용했습니다. 이 방법의 신뢰도는 낮으며 최소·최댓값은 참고 자료의 분포이지 통계적 신뢰구간이 아닙니다.

셀별 방법·이전 값·근거 링크·참고 범위·참고 시료 ID는 `ESTIMATION_LOG`, 원래 데이터는 `ORIGINAL_DATA`, 제외된 데이터는 `EXCLUDED_ROWS` 시트에 있습니다. 노란색은 추정값, 초록색은 Table S1에서 복구한 모재 조성입니다. 기존 값은 별도 색을 칠하지 않았습니다.

## 모델에 사용할 때

이 파일은 조성 보완을 검토하기 위한 결과입니다. 유사 합금 추정에 전체 데이터의 입력 조성을 참고했으므로 이 파일을 미리 채워진 상태로 교차검증에 넣으면 평가가 낙관적일 수 있습니다. **독립 평가에서는 원래 결측 데이터를 나눈 뒤, 추정에 사용할 참고 시료를 각 학습 분할에서만 선택해야 합니다.** 타깃은 어떠한 추정에도 사용하지 않았습니다. 이번 작업으로 모델을 다시 학습하거나 R²가 개선됐다고 주장하지 않습니다.

재생성: 프로젝트 루트에서 `python best_model/estimate_composition.py`를 실행하면 CSV·로그·제외 목록·요약을 생성합니다. XLSX는 같은 데이터의 열람용 사본입니다.
