# 단계별 열처리 피처 추가 예시

기존 377행과 같은 무작위 80:20 분리(seed42), 같은 SVR 설정으로 비교했다. 새 측정값은 추가하지 않았다.
추가한 단계별 정보는 감사된 17-4PH 15행에서만 제공된다. 다른 행은 미확인 상태이며 추정 매핑을 하지 않았다.
학습 쪽의 17-4PH는 SLM/NaCl 또는 소결/황산이며 외부 압연재/NaCl과 다르다. 외부의 8/32시간 시효는 SLM 학습 최대 4시간을 넘는다.
외부 논문은 이미 확인한 개발용 검증자료다. 모델 개선이나 새로운 독립 검증 성공으로 단정하지 않는다.

baseline: 무작위 test log R2=0.759734; 외부 log R2=-19.853347; 외부 기하평균 배수오차=7.752

stage_aware: 무작위 test log R2=0.761223; 외부 log R2=-73.193225; 외부 기하평균 배수오차=49.459

이 예시는 데이터 표현 추가의 효과를 확인하는 고정 설정 비교다. 제조법별 겹치는 관측이 부족하므로 용체화 시간/냉각 효과를 식별했다고 주장하지 않는다. 다음은 압연 17-4PH/NaCl의 같은 범위 실측값을 확보하고 새 논문을 따로 남겨 검증한다.
